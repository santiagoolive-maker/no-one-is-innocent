# NO ONE IS INNOCENT

Proyecto Integrador 2026. Aventura grafica de decisiones para web.

Klark es un exmilitar que trabaja como guardaespaldas de Adrian Veyra. Una amenaza contra Veyra reactiva el caso BLACK VEIL y lleva a Klark a investigar a ZENITH, una organizacion que opera en las sombras.

## Avance real del Sprint 2

Este repositorio muestra los recursos editables que el grupo ya produjo y la documentacion de preproduccion que los acompana. No presenta la aplicacion como terminada: la programacion navegable corresponde al Sprint 3.

- Personajes editables en `assets/personajes/editables/`.
- Escenario editable en `assets/escenarios/editables/`.
- Documento de preproduccion y registro de evidencias en `docs/`.
- Wireframe editable de una pantalla de decision en `docs/evidencias/`.
