# NO ONE IS INNOCENT

Proyecto Integrador 2026. Aventura grafica web de decisiones, misterio y tecnologia.

Klark trabaja como guardaespaldas de Adrian Veyra. Cuando aparecen pistas del caso BLACK VEIL, debe decidir si protege a Veyra, investiga a ZENITH o enfrenta las consecuencias de sus decisiones.

## Entrega actual del Sprint 2

El documento de preproduccion actual es `docs/Sprint_2_final.docx`. Reemplaza por completo las versiones anteriores.

- Seis nodos narrativos con situaciones, opciones y consecuencias.
- Variables, estados narrativos y condiciones de los finales.
- Identidad visual 2D realizable por el equipo.
- Mockups, propuesta de HUD y cinemática introductoria.
- Recursos prioritarios para Produccion Multimedial.

## Recursos editables

- `assets/personajes/editables/klark.ai`
- `assets/personajes/editables/adrian_veyra.ai`

Los dos archivos se abren y editan con Adobe Illustrator. Las siguientes evidencias se incorporaran a medida que el grupo las produzca: capas de animacion, exportaciones PNG, escenario de la oficina y pruebas de movimiento.

## Estructura inicial

```text
assets/    Recursos editables del proyecto
docs/      Documento de preproduccion
public/    Recursos que usara la WebApp
src/       HTML, CSS y JavaScript iniciales
```

## Equipo y metodologia

El grupo distribuye las tareas por partes. Cada tarea debe indicar responsable, estado, archivo esperado y evidencia de finalizacion. Los aportes se registran con commits descriptivos para que puedan revisarse individualmente.

## Abrir la base web

Abrir `src/index.html` en un navegador muestra una pantalla inicial de prueba. Esta base no es el juego terminado: solo deja preparada la estructura para comenzar el Sprint 3.
