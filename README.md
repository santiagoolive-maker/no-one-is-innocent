# NO ONE IS INNOCENT

WebApp de aventura grafica de decisiones desarrollada como Proyecto Integrador 2026.

Klark, un exmilitar convertido en guardaespaldas, descubre que su cliente Roman Bellic esta conectado con BLACK VEIL, una operacion de su pasado, y con la organizacion secreta ZENITH. Las decisiones del jugador afectan la investigacion, la moralidad, la lealtad, la confianza y la corrupcion de Klark.

## Flujo de trabajo

1. Crear una rama `feature/nombre-tarea`.
2. Realizar commits breves y descriptivos.
3. Abrir una solicitud de cambios para revisar antes de integrar a `main`.
4. Probar el flujo afectado y registrar el resultado en el tablero.
