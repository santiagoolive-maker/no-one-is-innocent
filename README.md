# No One Is Innocent

Aventura gráfica de decisiones del Proyecto Integrador 2026. Klark, un exmilitar que trabaja como guardaespaldas, investiga la relación de Adrián Veyra con BLACK VEIL y ZENITH.

## Cómo jugar

Descargá el repositorio y abrí [src/index.html](src/index.html) en el navegador, o serví la carpeta completa con un servidor estático y entrá en `/src/`. Elegí **Nueva partida** para empezar. **Continuar partida** retoma el avance mientras la pestaña siga abierta.
